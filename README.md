# noitom_mocap_api_single_sensor

**Notes / starter for reading acceleration from a single Perception Neuron 3 sensor** (example: RightHand) through the Noitom **Mocap API**.

Intended for mocap users and researchers who need a **single-IMU** stream instead of a full suit setup.

> This GitHub repository is currently empty of code. Use it as the home for scripts and docs as they are published. Until then, refer to Noitom’s official Mocap API documentation for Perception Neuron 3.

## Planned scope

- Connect to Mocap API
- Select one sensor (e.g. RightHand)
- Stream acceleration for logging or real-time analysis
